# Обзор проекта

ChainWise помогает предварительно исследовать Solidity-контракты: загрузить исходники, получить результаты статического анализа и задать вопрос по коду с цитатами.

## Возможности

- Загрузка `.sol`, `.zip` или верифицированного кода через Etherscan для Ethereum, BSC и Abstract.
- Регистрация по почте и паролю, JWT, вход через Google, роли `user` и `admin`.
- Компиляция solc, AST и отчёт Slither; разбиение кода и векторизация FastEmbed MiniLM для Qdrant.
- Опрос состояния индексации в интерфейсе, найденные проблемы с фильтрами, переход к строкам исходника.
- Экспериментальная оценка A–D с указанием источника `risk_model`.
- RAG-чат с цитатами, потоком SSE и историей; PDF-отчёт.
- Изоляция контрактов по пользователю и настраиваемые квоты.

## Для кого

Разработчики Solidity могут использовать сервис для предварительной проверки, аудиторы — для навигации по исходникам, инженеры — для изучения полного процесса анализа контрактов.

## Особенности использования

Оценка A–D — дополнительный эвристический индикатор, а не вероятность эксплуатации или аудит. XGBoost обучен на синтетических метках; при недоступной модели применяется эвристика. Чувствительность и специфичность на реальных уязвимостях неизвестны. См. [описание модели](./risk-score-model-card.md).

Чат отвечает по проиндексированным фрагментам. Генерация требует ключа сервиса, совместимого с OpenAI; по умолчанию используются OpenAI и GPT-4o-mini. PDF содержит результаты, но не полный исходный код.

Сборка Docker выполняется без сети после подготовки зависимостей на Linux x86_64 с Python 3.12 и Node.js 20+. Используются pip, FastEmbed ONNX и заранее установленный solc. Локальное окружение не заменяет подготовку рабочего развёртывания, резервного копирования и мониторинга.
