## Быстрый старт

```bash
cp .env.example .env
make deps          # с интернетом
make up            # без сети
```

- Веб-интерфейс: http://localhost:3001
- Документация API Swagger: http://localhost:8001/docs
- Панель Qdrant: http://localhost:6333/dashboard

## Структура репозитория

```
chainwise/
```
