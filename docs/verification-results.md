В полном сценарии генерация текста была заменена заглушкой. Векторизация, поиск Qdrant и проверка путей и строк цитат выполнялись настоящим кодом. Внешняя языковая модель и качество её ответа не проверялись.

XGBoost не запускался: на диске не хватило места для зависимости NCCL. Выполнен штатный эвристический расчёт, API вернул `risk_model=heuristic`.

Анализатор работал во временном Python-контейнере. Ограничения прав и ресурсов из Compose в этом прогоне не измерялись. Полный серверный набор локально не запускался; он выполнен опубликованными проверками GitHub Actions.

Снимки интерфейса в репозитории отсутствуют. Архитектура представлена диаграммой Mermaid.

## Повторение

Подготовьте `.env` и зависимости через `make deps`, запустите Compose и следуйте [инструкции проверки сценария](./smoke-e2e.md). `CHAINWISE_LIVE_E2E_MOCK_LLM=1` позволяет проверить настоящие интеграции без внешнего ключа языковой модели.
